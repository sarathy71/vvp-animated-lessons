# Sloka 04 — The Five Lamps of Learning

Complete source lesson pack for the Sloka Adventure Engine.

Included:
- user-supplied Guruji lesson video (`assets/video/lesson.mp4`)
- preview video compiled from the supplied narration master
- the supplied narration master WAV
- Day 0 through Day 5 low-lit progressive lamp scenes
- Day 5 finale scene
- sloka and child-friendly phonics hint
- progress icon
- ball/victory SFX
- lesson configuration with a `light` daily challenge animation hint

Core progression:
- recital 1–4: daily balls only
- recital 5: daily completion; exactly one additional lamp becomes lit
- Day 5: fifth lamp lights first, then the existing finale sequence runs

The engine/framework is responsible for animating the transition between cumulative scenes instead of instant swapping.
