# Sloka 06 — The Path to Gauri's Garden

Week 6 lesson pack for the reusable Sloka Adventure Engine.

## Practice rule
- Five complete Guruji recitals per calendar day.
- Recitals 1–4 fill daily balls only.
- Recital 5 completes the day and advances the weekly challenge exactly once.
- One additional stepping stone glows after each completed day.
- Day 5 shows all five glowing stones before the existing finale sequence.
